# ТонПлат — обновление сайта (Zapnoty + MAX + cookie-уведомление)

Этот файл входит в **небольшой архив исправлений** к ранее скачанному полному архиву `tonplat-ready-for-publication.zip` (118 файлов). Распакуйте файлы исправлений с заменой в корень сайта / репозитория. Не требуется загружать повторно фотографии и `menu-data.js`.

## Что изменено
- При первом открытии главной страницы видна плашка «Мы используем файлы cookie» с выбором. Технический cookie `tonplat_cookie_choice_v2` живёт до 180 дней; корзина между посещениями — только после разрешения.
- Формы отправляют заявки в **Zapnoty Forms** по HTTPS; маршрут в **MAX** задаётся в кабинете Zapnoty. Убрана устаревшая ручная отправка через WhatsApp/Telegram.
- Исправлены `privacy.html`, `consent.html`, `cookies.html`, `terms.html`: отражена обработка данных на серверах Zapnoty и в MAX, права субъектов и настройки хранения.
- Нумерация не показывается также в карточке подробностей блюда.

## Без обязательной настройки отправка НЕ работает

1. В кабинете **https://app.zapnoty.ru/** создайте **Forms / Форму**. Разрешите реальный домен сайта в `allowed_origins` (например, `https://ch1lov1c.github.io`, либо ваш собственный домен; без пути). Получите публичный `form_id`.
2. В маршрутах (routes) этой формы укажите **получателя в MAX** и проверьте, что этот бот/аккаунт действительно может получать сообщения.
3. Откройте `config.js` и укажите идентификатор: `zapnoty: { formId: "ВАШ_FORM_ID", endpointBase: "https://api.zapnoty.com/f/" }` (уже есть структура; замените только пустое значение). **API-ключи `zn_...` не вставляйте в сайт**. Публичный endpoint формы не требует секретного API-ключа.
4. Опубликуйте сайт по HTTPS и отправьте **тестовую заявку**. Проверьте факт появления в кабинете Zapnoty и получение уведомления в MAX. Без этого теста нельзя считать доставку готовой.
5. Если Zapnoty выдаст для вашей формы конкретный публичный URL, сверяйте его с `https://api.zapnoty.com/f/<form_id>`; при различии обратитесь к актуальной документации Zapnoty.

## Что ещё обязательно проверять владельцу бизнеса

Публикация документов на сайте **не означает автоматическое соответствие законодательству**. В частности, до запуска коммерческой обработки нужно проверить точность реквизитов/адреса, уведомление Роскомнадзора по статье 22 Закона №152-ФЗ, внутренние документы, учёт согласий, назначение ответственного, фактические сроки и место хранения заявок, договоры и поручения обработки с Zapnoty/MAX, локализацию баз данных граждан РФ, отсутствие незаконной трансграничной передачи, защиту аккаунтов и процедуру обработки запросов/отзыва согласия. При изменении cookies или подключении аналитики обновите механизм согласия и документы.

Ссылки на нормы: https://www.consultant.ru/document/cons_doc_LAW_61801/ (ФЗ №152); https://zapnoty.ru/features/forms (Zapnoty Forms). Для продажи/заказа дистанционно проверьте также требования законодательства о защите прав потребителей и информацию об изготовителе/товаре.


## Обновлённый первый экран для мобильных (ноябрь 2026)

На смартфонах с шириной экрана до 767 px первый экран теперь показывает краткое предложение «Фуршеты и кейтеринг в Самаре», преимущества (от 400 ₽/гость, 94 блюда, без минимального заказа) и заметную кнопку «Собрать на стол». Кнопка открывает существующий конструктор заказа. Мобильная шапка компактная: логотип, название и кнопка заказа, без перегруженной навигации. На компьютерах осталась прежняя компоновка. Стили мобильного первого экрана встроены в `index.html`.

## Перед запуском

Проверьте `config.js`: для реальной отправки заявок через Zapnoty требуется установить публичный `zapnoty.formId` (по умолчанию пустой), настроить разрешённый домен и маршрут уведомлений в MAX. Никакие секретные API-ключи публиковать нельзя. Пока форма не настроена, пользователю отображается ошибка вместо ложного подтверждения доставки. Уведомление о cookie и документы включены. Для соответствия требованиям о персональных данных нужно дополнительно проверить реальные практики вашей организации (место хранения данных Zapnoty/MAX, уведомление РКН, реквизиты и т. д.).
